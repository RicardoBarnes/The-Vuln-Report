## Vulnerability Management

| Resource | What It Is |
|---|---|
| [CISA KEV Catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) | Known Exploited Vulnerabilities — the list that matters most |
| [NVD (National Vulnerability Database)](https://nvd.nist.gov/) | The canonical CVE reference |
| [EPSS (Exploit Prediction Scoring System)](https://www.first.org/epss/) | Probability-based prioritization, not severity theater |
| [VulnCheck](https://vulncheck.com/) | Exploit intelligence beyond the NVD |
| [Nuclei Templates](https://github.com/projectdiscovery/nuclei-templates) | Community-driven detection templates |
